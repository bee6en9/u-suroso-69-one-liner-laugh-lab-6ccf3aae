A single funny line answering the prompt: the excuse a robot vacuum gives
after eating a sock.

> My lidar missed your sock, my bumper nudged it, and my brush roll made an executive decision.

## How it works

`main.ts` (Node, no external dependencies) writes that one deterministic line
to `/output/entry.txt`. Run it with:

```sh
node main.ts
```
